## 2. 内环: 姿态控制 (pitch/yaw → TVC 角度)

**目标**: 保持火箭垂直 (pitch=0, yaw=0)。

### 2.1 动力学模型

俯仰轴转动方程:
```
Iyy · θ̈ = F · L · δ + 扰动
```
- θ: 俯仰角, δ: TVC 偏转角, F·L = 35 × 0.5 = **17.5 N·m/rad** 控制力矩系数

### 2.2 极点配置设计

取闭环二阶系统设计指标:
- 自然频率 ωn = 8 rad/s (响应快, 火箭姿态稳定时间 ~0.4s)
- 阻尼比 ζ = 0.7 (临界阻尼附近, 无超调)

标准 PD 形式 `δ = Kp·θ + Kd·θ̇` 代入动力学:
```
Iyy·θ̈ = F·L·(Kp·θ + Kd·θ̇)
θ̈ - (F·L·Kd/Iyy)·θ̇ - (F·L·Kp/Iyy)·θ = 0
```
对比二阶标准型 `θ̈ + 2ζωn·θ̇ + ωn²·θ = 0` (注意误差符号, 取负号):

```
Kp = ωn²·Iyy / (F·L) = 64 × 0.200 / 17.5 ≈ 0.73
Kd = 2ζωn·Iyy / (F·L) = 2×0.7×8×0.200 / 17.5 ≈ 0.128
Ki = 0.1·Kp = 0.073   (小积分消除静态偏差/安装偏置)
```

### 2.3 内环参数 (实现值)

```
pid_att_pitch = pid_att_yaw = { Kp 0.73, Ki 0.073, Kd 0.128, 输出 ±12° }
```

输出限幅 ±12° 对应 TVC 物理行程 (116mm 内径下安全间隙)。

## 3. 外环: 高度控制 (alt → 推力 N → 油门)

**目标**: 飞到 50m 目标高度并平稳下降着陆。

### 3.1 动力学模型

垂直通道 (含重力补偿):
```
m(t)·ä = F_cmd - m(t)·g
```
- m(t) = m_dry + m_fuel(t) ≈ 1.65~1.80 kg, 平均 **1.67 kg**

### 3.2 极点配置设计

取:
- ωn = 2 rad/s (慢于内环 4 倍, 避免内外环耦合振荡)
- ζ = 0.8

```
Kp = ωn²·m_avg = 4 × 1.67 ≈ 6.7 N/m
Kd = 2ζωn·m_avg = 3.2 × 1.67 ≈ 5.3 N·s/m
Ki = 0.3·Kp = 2.0 N/(m·s)
```

### 3.3 重力补偿与油门映射

```
F_cmd = PID(alt_err) + m(t)·g        // PID 输出 + 实时重力补偿
throttle = clamp(F_cmd / F_max, 0, 1) // 油门 0~1
```

- 悬停点: throttle = m·g/F_max = 1.8×9.81/35 ≈ **0.505** (推重比倒数)
- 外环 PID 输出限幅 [−5, F_max×0.8=28N], 补偿后总推力上限 35N

### 3.4 外环参数 (实现值)

```
pid_alt = { Kp 6.7, Ki 2.0, Kd 5.3, 输出 -5~28N }
```

### 3.5 燃料保护

```
燃料 <5% 时: 近地(alt<3m) 油门 0.35 缓冲, 否则限油门 ≤0.3 缓慢下降
```

## 4. 实现细节 (pid_local.cpp)

| 特性 | 实现 |
|---|---|
| 积分 | 限幅防饱和 (i_max) |
| 微分 | 一阶低通滤波 (α=0.7) |
| 速率限幅 | 舵机 600°/s, 油门 200%/s (actuators.cpp) |
| 采样 | 50Hz 固定 dt=0.02s |
| 角速度使用 | 由误差导数隐含 (d 项 = kd·de/dt ≈ kd·(-角速度)) |

## 5. 与地面 LLM 的融合

```
输出 = 本地PID + 0.25 × (LLM指令 - 本地PID)   // 25% 权重修正
```

- LLM 输出 throttle[0~1], tvc[-1~1] → TVC 换算 ×12° 与 PID 度单位对齐
- 指令超时 300ms → 回退纯本地 PID
- 摄像头不可靠时水平增益降至 0.3 (见 rocket_flight.ino apply_control)

## 6. 验证建议

- 仿真: 用 `ai_controller/pid_controller.py` (同构 Python 版) 离线回放 SD 卡日志对比
- 台架: 舵机扫频确认 TVC 响应, 用推力秤标定油门-推力曲线
- 迭代: 若姿态振荡增大, 降 ωn (内环) 或降 Kp; 若高度过冲, 提高外环 Kd/ζ
